# 나의 세계관 위키

이곳은 국가, 인물, 역사, 지리와 설정을 정리하는 개인 위키입니다.

!!! note "첫 문서"
    왼쪽의 `국가` 메뉴를 열고 `헤르잔 공화국`을 눌러 국가 문서 예시를 확인하세요.

## 주요 문서

| 분류 | 설명 |
|---|---|
| 국가 | 국호, 국기, 수도, 인구, 정치체제 |
| 인물 | 지도자, 정치인, 역사적 인물 |
| 역사 | 시대별 사건과 전쟁 |
| 지리 | 대륙, 도시, 산맥과 해역 |

## 최근 작업

- 위키 개설
- 국가 정보상자 제작
- 첫 번째 국가 문서 작성
