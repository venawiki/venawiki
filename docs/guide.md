# 위키 사용법

## 문서 파일의 위치

실제 문서는 모두 `docs` 폴더에 들어갑니다. 문서 파일의 확장자는 `.md`입니다.

## 가장 자주 쓰는 문법

```markdown
# 문서 제목

## 큰 문단

### 작은 문단

일반적인 설명입니다.

- 목록 1
- 목록 2

[다른 사이트로 가는 링크](https://example.com)
```

## 새 국가 문서 만들기

1. `docs/templates/country-template.md`를 복사합니다.
2. 복사한 파일을 `docs/nations/국가이름.md`라는 이름으로 저장합니다.
3. 파일 안의 예시 내용을 새 국가의 설정으로 바꿉니다.
4. `mkdocs.yml`의 `nav` 아래에 새 문서를 추가합니다.

자세한 업로드와 수정 방법은 사이트가 처음 열린 뒤 차근차근 진행합니다.
